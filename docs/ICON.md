# Addon icon

The custom WIIIUI Forever icon was created with the built-in imagegen tool using the Warcraft III icon reference supplied by the maintainer. It combines a gold W, teal Roman III, and large UI lettering inspired by the WoW title treatment. It is a community addon graphic, not an official Blizzard icon.

- PNG: [`images/addon-icon.png`](images/addon-icon.png)
- Client texture: [`../WIIIUIForever/art/icon.tga`](../WIIIUIForever/art/icon.tga), 256×256 uncompressed RGBA TGA.
- The TOC's `IconTexture` metadata supplies the icon to Forever's native AddOn List.
